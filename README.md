# Gidos Hydranten-Erbe

Ein Idle-Spiel fürs Handy: Gido hat 100 Hydranten geerbt und dich zum Verwalter gemacht. Poliere, vermiete, sammle, schick einen nach Berlin (das Porto ist absurd) und übernimm irgendwann Gidos nächste Erbschaft.

**Spielen:** https://bobsli98.github.io/Hydrant/

Alles steckt in `index.html` (kein Build nötig). `og.jpg` ist das Vorschaubild für WhatsApp & Co.
