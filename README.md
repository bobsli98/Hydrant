# Gidos Hydranten-Erbe

Ein Idle-Spiel fürs Handy: Gido hat dir 100 Hydranten vererbt. Poliere, vermiete, sammle, schick einen nach Berlin (das Porto ist absurd) und tritt irgendwann das nächste Erbe an.

**Spielen:** https://bobsli98.github.io/Hydrant/

Alles steckt in `index.html` (kein Build nötig). `og.jpg` ist das Vorschaubild für WhatsApp & Co.
